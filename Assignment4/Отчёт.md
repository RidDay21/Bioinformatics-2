## 4. Заключение

### Интересные варианты
Наибольший интерес представляют миссенс-варианты в генах *BCR* (участвует в формировании онкогена BCR-ABL1) и *EP300* (регуляция хроматина). Анализ их частот в gnomAD наглядно демонстрирует процесс отсева вариантов-кандидатов при поиске патогенных мутаций.

### Ограничения используемых данных
1. **Канонический транскрипт:** Аннотация по MANE Select / Canonical может упускать варианты, функционально важные для альтернативных тканеспецифичных изоформ.
2. **Ограничения ClinVar:** Часть записей содержит низкий уровень достоверности (1 star) или конфликтные оценки от разных лабораторий.
3. **Отсутствие в gnomAD:** Не всегда означает патогенность; может быть следствием редкого варианта или низкой плотности покрытия региона.
4. **Тип вариантов:** В датасете присутствуют только однонуклеотидные замены (SNV), без структурных перестроек и indel-мутаций.
